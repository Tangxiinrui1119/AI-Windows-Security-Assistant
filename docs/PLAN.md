# 三年成长规划（大二 → 大三 → 大四）

> 与 ChatGPT 共同制定，2026 年 9 月起执行。
> 本文件是规划的权威版本，随执行情况持续更新。

## 一、最终目标

- 现在：大二，信息安全专业；C++、面向对象、指针、项目拆解还不够熟。
- 不追求「大二就变成大神」，而是追求：
  **大二学会做东西 → 大三做出真正的软件 → 大四把它变成拿得出手的作品。**
- 毕业时，GitHub 上不是一堆零散的课程作业，而是有一个真正属于自己的长期项目。

## 二、主项目：AI Windows 安全助手

进化路线：

```
PowerShell 查看自启动项
  ↓
Windows 小工具
  ↓
电脑信息检测
  ↓
自启动项分析
  ↓
系统安全检查
  ↓
网络状态分析
  ↓
风险判断
  ↓
AI 解释
  ↓
AI Windows 安全助手
```

最终再考虑：**普通用户版 + 开发者安全工具（开发 + 安全）**。

方向选择：先走 **A（偏开发）**，长期方向慢慢走向 **C（开发 + 安全）**。

## 三、大二：从「会写代码」变成「能做东西」

**核心目标**：建立编程基础 + 第一次真正独立完成软件。不追求项目多，把基础补起来。

### ① C++

重点路线：

```
基础语法 → 指针 → 引用 → 函数 → 结构体 → 类与对象
→ 继承/多态 → STL → 文件操作 → 项目
```

当前卡点：**指针、类和对象、项目怎么拆** —— 必须真正搞懂。
不是背概念，而是 **学完 → 马上拿到项目里用**。

### ② Python

等 C++ 基础稍微稳定后开始。目标：能用 Python 快速写实用工具（读取文件、处理数据、调用 API、自动化任务、简单 GUI）。以后 AI 功能主要用 Python。

### ③ Git + GitHub

从 `git add / commit / push` 逐渐升级到：branch → merge → Pull Request → Issue → Release → CI/CD。**边做项目边学**，不需要一次全部学会。

### ④ PowerShell

马上开始。第一阶段：用 PowerShell 查看 Windows 自启动项。然后慢慢理解：

```
PowerShell → Windows 系统 → 进程 → 文件 → 注册表 → 系统权限
```

这会让我逐渐从「写代码的人」变成「理解电脑的人」。

## 四、大二项目路线（Level 1~5）

| Level | 内容 | 产出 |
|-------|------|------|
| 1 | PowerShell 小实验：查看电脑有哪些自启动程序 | 一条能跑的脚本 |
| 2 | C++ / Python 小工具：把功能做成自己的程序 | 可执行的小程序 |
| 3 | Windows 信息检测工具：电脑信息、CPU、内存、磁盘、系统版本、进程、启动项 | 信息检测工具 |
| 4 | 安全检查：「这个东西正常吗？」——来源？路径？是否可信？是否需要提醒用户？ | 安全检查功能 |
| 5 | 真正的软件雏形：可以运行、放到 GitHub、别人能下载尝试 | 大二最重要的成果 |

## 五、大三：从「小工具」变成「真正的软件」

### 大三上

重点学习**计算机网络**：IP、TCP、UDP、HTTP、DNS、端口、连接。
把知识放进项目，例如：「我的电脑现在有哪些网络连接？」
学网络不再是「老师让我背 TCP」，而是「我想让我的软件检查电脑连接了什么」。

### 大三下

正式加入 **AI**。例如用户问「为什么我的电脑开机越来越慢？」：

```
扫描电脑 → 发现启动项很多 → 分析启动项 → AI 解释 → 告诉用户可能的原因
```

AI 不是为了「项目里必须有 AI」，而是 AI 真正解决问题。

## 六、大四：把它变成代表作品

大四不再学一堆新东西，而是把前三年的东西**整合**起来。重点变成：
性能、架构、安全、AI、用户体验、开源、文档、部署。

逐渐加入真正的信息安全能力：

```
系统风险 → 网络风险 → 文件风险 → 配置风险 → AI 风险解释
```

甚至可以开始尝试**代码安全分析**。

整个路线闭环：

```
大二：基础 + 开发
  ↓
大三：软件 + AI + 网络
  ↓
大四：软件 + AI + 安全
  ↓
毕业：真正属于自己的项目
```

## 七、每周学多少：碎片化学习

- 每天课外大约投入 1~2 小时，没有固定的大块时间。
- 不采用「每天晚上固定学习三小时」的计划，而是：
  - 今天有 **30 分钟** → 做一个小任务
  - 今天有 **1 小时** → 学一点 + 做一点
  - 今天有 **2 小时** → 学习 + 项目

## 八、最重要的一条规则

**不追求每天完成很多，追求「一直做」。**

```
今天：指针课 30 分钟
明天：指针练习 30 分钟
后天：PowerShell 30 分钟
再后天：项目 1 小时
```

半年之后回头看，会比「激情学习两周然后摆烂一个月」有效得多。

## 九、图书馆模式

去图书馆没法一直语音也没问题，新开聊天输入：

- 「开始今天的任务，我今天有 40 分钟。」
- 「开始今天的任务，我今天有 1 个小时。」

AI 就按照三年规划安排当天任务：只有 20 分钟就给 20 分钟能完成的小任务；状态特别好有 2 小时，就再往后推进。

## 十、AI 在规划里的角色：老师 + 项目导师

- **老师**：把 C++、Python、网络、AI、安全讲懂，用能理解的方式讲。
- **项目导师**：告诉现在该学什么、为什么学、学完拿来干什么。
  例如学指针，不是「今天学习指针」，而是「为什么必须学指针？因为以后要处理 Windows 系统资源」。

## 十一、关于刷题

不把三年计划设计成「洛谷 1000 题 → 刷完 → 毕业」。但也不是完全不做题，而是**需要的时候刷**：

```
学知识 → 做几个小题 → 写一个小程序 → 马上进入项目
```

## 十二、最终 GitHub 目标

毕业时打开 GitHub，不是 `homework1`、`test2`、`cpp-study-final`，而是一个真正像样的 **AI-Windows-Security-Assistant**，里面有：

- README
- 架构图
- 源代码
- Issue
- 版本（Release）
- 开发记录
- 使用说明

最好还能有别人真的使用、提 Issue、提交 PR。
