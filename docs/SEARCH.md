# 知识点搜索

网站首页和每个阅读器页面顶部都有搜索栏。输入关键词后，可以按分类筛选，查看命中的正文片段，点击结果即可在阅读器中定位并高亮相关内容。

- 支持中文、英文术语和代码名称，例如 `三次握手`、`ACL`、`new delete`、`C++`。
- 多个关键词用空格分隔，结果必须同时包含这些关键词。
- 使用 `Ctrl + K`（macOS 为 `⌘ + K`）可快速聚焦搜索栏。

## 收录范围

收录 `notes/` 下的课程 Markdown 笔记，目录页 `README.md` 和空白占位文件不作为搜索结果。分类由笔记所在目录决定，信息安全笔记额外显示 Part 编号。

## 更新方式

`docs/search-index.json` 提供初始全文索引。搜索页打开后会检查 GitHub 上的最新笔记目录，只下载新增或有修改的笔记，并在浏览器中缓存结果。若 GitHub 目录接口暂不可用，则从 `notes/README.md` 及各分类的目录页发现笔记并同步正文。新增、移动笔记时应同步更新这些目录页。删除或移动的文件也会从下一次成功同步的搜索目录中移除。五分钟内重复打开使用已同步缓存；同步失败仍可搜索已有索引，并提供重试按钮。

新增笔记不需要单独配置搜索服务。需要更新随网站发布的初始索引时，在仓库中运行：

```text
node scripts/build-search-index.cjs
node --test tests/search.test.cjs
```

然后一并提交生成的 `docs/search-index.json`。构建和搜索均不需要安装依赖。
