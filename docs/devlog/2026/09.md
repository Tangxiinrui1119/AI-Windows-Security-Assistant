### 今日实践
```powershell
Get-CimInstance Win32_StartupCommand
```
这条命令用来查看 Windows 启动项。今天用它，是因为它一条命令就能把注册表 Run 键和启动文件夹里的启动项汇总出来，是认识「启动项」最直观的入口；配合管道还练习了筛选输出。
另外用 `whoami /user` 查看了当前用户 SID；仓库与主页的搭建过程见提交历史。

### 今日总结
今天真正建立起来的认识：PowerShell 能直接「看到」Windows 的注册表；启动项只是注册表里的一组键值；而注册表背后是「用户 = SID」的身份体系——用户名是给人看的，SID 才是 Windows 真正用来识别身份的。从「查启动项」一个动作，顺藤摸瓜摸到了 Windows 身份与安全模型的大门。
