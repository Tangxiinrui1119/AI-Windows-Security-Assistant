# 学习日志（Dev Log）

这里记录每一天的学习过程。规则只有一个：**一直做**。

## 怎么记

1. 复制 [TEMPLATE.md](TEMPLATE.md) 的内容
2. 按 `年/月.md` 归档，同一个月写在同一个文件里（例如 `2026/09.md`）
3. 每条日志 3 分钟以内写完，不用写作文

## 图书馆模式

去图书馆没法和 AI 语音时，新开聊天输入：

> 开始今天的任务，我今天有 X 分钟。

AI 会按 [三年规划](../PLAN.md) 给你安排当天任务。完成后回到这里记一笔。

## 日志约定

- 每条日志按时间倒序追加（最新的在最上面）
- 「卡住的地方」一定要写 —— 下次继续就从这里开始
- 每个月结束，翻一遍当月日志，很有成就感
