计算机网络复习笔记

按课件章节复习，从链路层传帧、网络层逐跳转发，串起运输层的进程通信。第3～6章提供不依赖JavaScript的静态全文。

  • 第1章 计算机网络概述
  • 第2章 物理层
  • 第3章 数据链路层：计算机网络第3章中文复习笔记：帧、CRC、PPP、CSMA/CD、MAC地址、以太网交换机、VLAN与高速以太网。
  • 第4章 网络层：计算机网络第4章中文复习笔记：IP与CIDR、ARP、IPv4首部和分片、最长前缀匹配、ICMP、IPv6、RIP、OSPF、BGP、VPN与NAT。
