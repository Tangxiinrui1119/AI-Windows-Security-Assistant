## 添加内容

学科和技术主题保留各自的目录。新增笔记时，把 Markdown 放入对应主题的目录并更新该目录的 README。新主题需要在课内或课外目录中增加入口。实验项目集中登记在[实验项目目录](../project/README.md)。

笔记可以标注日期、关联项目与复习目标。建议用 `NN-主题.md` 为有顺序要求的章节命名。提交前按[搜索维护说明](../docs/SEARCH.md)更新索引。
