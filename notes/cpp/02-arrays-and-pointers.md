# 一、数组在内存中的基本形式

例如：

```cpp
int arr[4] = {10, 20, 30, 40};
```

数组中有 4 个 `int` 元素：

```text
arr[0] = 10
arr[1] = 20
arr[2] = 30
arr[3] = 40
```

数组中的元素在内存中是连续存放的。

假设：

```text
一个 int 占 4 字节
```

并且：

```text
arr[0] 地址 = 1000
```

那么可能有：

```text
arr[0] 地址 = 1000
arr[1] 地址 = 1004
arr[2] 地址 = 1008
arr[3] 地址 = 1012
```

因此数组可以理解成：

```text
arr

+------+------+------+------+
|  10  |  20  |  30  |  40  |
+------+------+------+------+
```

# 二、数组名与首元素地址

例如：

```cpp
int arr[4] = {10, 20, 30, 40};
```

在很多表达式中：

```cpp
arr
```

会自动转换成：

```cpp
&arr[0]
```

也就是：

> 数组第一个元素的地址。

因此下面的代码是合法的：

```cpp
int* p = arr;
```

可以理解成：

```cpp
int* p = &arr[0];
```

此时：

```text
p
↓
arr[0]
```

也就是说：

```cpp
p
```

保存的是：

```cpp
arr[0]
```

的地址。

因此：

```cpp
*p
```

就是对这个地址进行解引用，得到：

```cpp
arr[0]
```

例如：

```cpp
int arr[4] = {10, 20, 30, 40};

int* p = arr;

cout << *p;
```

输出：

```text
10
```

# 三、数组并不等于指针

今天一个非常重要的知识点是：

```text
数组 != 指针
```

不能简单地说：

```text
arr 就是一个指针
```

更准确的说法应该是：

> `arr` 本身是数组，但是数组名在很多表达式中会自动转换成指向数组首元素的指针。

例如：

```cpp
int arr[4] = {10, 20, 30, 40};
```

这里：

```cpp
arr
```

本身的类型是：

```cpp
int[4]
```

即：

> 包含 4 个 `int` 的数组。

而：

```cpp
int* p = arr;
```

这里的：

```cpp
p
```

才真正是：

```cpp
int*
```

即：

> 指向 `int` 的指针。

# 四、sizeof 可以帮助区分数组和指针

例如：

```cpp
int arr[4] = {10, 20, 30, 40};

int* p = arr;
```

假设：

```text
int = 4 字节
```

那么：

```cpp
sizeof(arr)
```

得到：

```text
16
```

因为：

```text
4 个 int × 4 字节
=
16 字节
```

即：

```text
sizeof(arr)
=
整个数组占用的空间
```

而：

```cpp
sizeof(p)
```

得到的是：

> 指针本身所占的空间。

在常见的 64 位环境下通常是：

```text
8 字节
```

因此：

```cpp
sizeof(arr)
```

和：

```cpp
sizeof(p)
```

并不相同。

这也说明：

> 数组本体和指针本体并不是同一个东西。

假设：

```cpp

int* p = arr;
```

那么：


指向：


表示：

> 向后移动一个 `int` 元素的位置。

因此：


指向：

```cpp
arr[1]
```

同理：

```cpp
p + 2
```

指向：

```cpp
arr[2]
```

```cpp
p + 3
```

指向：

```cpp
arr[3]
```

可以理解成：

```text
p
↓
arr[0]

p + 1
↓
arr[1]

p + 2
↓
arr[2]

p + 3
↓
arr[3]
```

# 六、p + 1 不是简单的地址 +1 字节

这是今天容易产生误解的地方。

例如：

```cpp
int* p;
```

因为：

```cpp
p
```

是：

```cpp
int*
```

所以：

```cpp
p + 1
```

表示：

> 向后移动一个 `int` 的距离。

如果：

```text
sizeof(int) = 4
```

那么：

```cpp
p + 1
```

在内存地址上通常相当于向后移动：

```text
4 字节
```

因此指针加法会根据：

```text
指针所指向的数据类型
```

自动决定移动多少字节。

# 七、使用指针访问数组元素

例如：

```cpp
int arr[4] = {10, 20, 30, 40};
```

因为：

```cpp
arr
```

在很多表达式中会转换成：

```cpp
&arr[0]
```

所以：

```cpp
*arr
```

就是：

```cpp
arr[0]
```

即：

```cpp
arr[0] == *arr
```

同理：

```cpp
arr + 1
```

指向：

```cpp
arr[1]
```

因此：

```cpp
*(arr + 1)
```

就是：

```cpp
arr[1]
```

继续：

```cpp
*(arr + 2)
```

就是：

```cpp
arr[2]
```

所以今天最重要的公式之一：

```cpp
arr[i] == *(arr + i)
```

例如：

```cpp
int arr[4] = {10, 20, 30, 40};

cout << arr[2] << endl;
cout << *(arr + 2) << endl;
```

两次都会输出：

```text
30
```

---

# 八、arr + i 与 *(arr + i) 的区别

这是今天需要牢牢记住的区别。

例如：

```cpp
arr + 2
```

表示的是：

```text
arr[2] 的地址
```

也可以理解成：

```cpp
&arr[2]
```

而：

```cpp
*(arr + 2)
```

表示：

> 找到 `arr[2]` 的地址以后，再进行解引用，取得里面的数据。

例如：

```cpp
int arr[4] = {10, 20, 30, 40};
```

那么：

```cpp
arr + 2
```

对应：

```text
arr[2] 的地址
```

而：

```cpp
*(arr + 2)
```

对应：

```text
30
```

因此：

```text
arr + i
↓
第 i 个元素的地址

*(arr + i)
↓
第 i 个元素本身
```

---

# 九、修改数组元素

因为：

```cpp
*(arr + i)
```

代表的就是：

```cpp
arr[i]
```

这个元素本身，所以不仅可以读取，还可以修改。

例如：

```cpp
int arr[4] = {10, 20, 30, 40};

*(arr + 2) = 100;
```

相当于：

```cpp
arr[2] = 100;
```

因此数组会变成：

```text
10 20 100 40
```

# 十四、为什么数组传入函数时通常还要传 size

由于数组传进函数以后，函数参数里的：

```cpp
arr
```

本质上只是一个指针。

这个指针知道：

```text
数组从哪里开始
```

但它本身并不知道：

```text
这个数组到底有多少个元素
```

例如：

```cpp
void test(int arr[])
```

从这个函数本身来看，它无法仅靠 `arr` 判断调用者传进来的是：

```cpp
int a[5];
```

还是：

```cpp
int b[100];
```

因此实际编程中经常会额外传入数组长度：

```cpp
void printArray(int arr[], int size)
```

其中：

```text
arr
→ 数组从哪里开始

size
→ 数组有多少个元素
```

```cpp
change(nums, 5);
```

```cpp
nums
```

```cpp
&nums[0]
```

```cpp
arr
```

```text
实际按 int* arr 处理
↓
arr 保存 nums[0] 的地址
```

所以函数能够：

```text
通过 arr
↓
访问原数组
↓
修改原数组元素
```

但是函数仅靠：

```cpp
arr
```

无法知道：

```text
原数组到底有多少个元素
```

因此经常使用：

```cpp
void func(int arr[], int size)
```

# 二十五、今天应该牢牢记住什么

今天最重要的几句话：

```text
1. 数组本身不是指针。

2. 数组名在很多表达式中会自动转换成数组首元素的地址。

3. arr 通常可以理解为 &arr[0]。

4. arr + i 表示第 i 个元素的地址。

5. *(arr + i) 表示第 i 个元素本身。

6. arr[i] == *(arr + i)。

7. 函数参数中的 int arr[] 实际按 int* arr 处理。

8. 数组传入函数以后，函数通常不知道数组长度。

9. 因此经常需要同时传入 arr 和 size。

10. 通过函数中的 arr 修改元素，会直接影响原数组。
```
