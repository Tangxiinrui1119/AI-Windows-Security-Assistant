## 二、Python 的产生与特点

- Python 由 Guido van Rossum（吉多·范罗苏姆）设计。
- 1989 年开始构思，1991 年发布第一个公开版本。
- Python 的特点：
  - 语法简洁、可读性较好。
  - 标准库功能丰富。
  - 跨平台、可移植。
  - 可扩展，可与 C、C++、Java 等结合。
  - 拥有大量第三方库。
- PPT 中列出的不足：
  - 执行速度相对 C/C++ 较慢。
  - 源代码直接参与运行，代码加密较困难。

## 四、Python 开发环境

### IPython

交互式计算和开发环境，可直接输入表达式并查看结果。

### Jupyter Notebook

- 交互式笔记本。
- 可运行代码、编辑 Markdown、公式和可视化内容。
- 本质上是一个 Web 应用程序。

### Anaconda

用于科学计算的 Python 发行版，包含 Python、conda 以及大量科学计算和数据分析相关包。

### PyCharm

Python IDE，提供调试、语法高亮、项目管理、代码跳转、自动提示等功能。

## 五、编译与解释

### 编译

编译是把源代码一次性转换成目标代码，执行这个过程的程序叫编译器。

特点：

- 先翻译，再运行。
- 编译后生成的目标代码执行速度通常较快。
- 运行目标代码时不需要再次逐条解释源代码。

### 解释

解释是把源代码逐条转换并逐条运行，执行这个过程的程序叫解释器。

特点：

- 每次运行都需要解释器参与。
- 源代码保留，修改和调试方便。
- 只要目标平台有对应解释器，可移植性较好。

课程中可先这样记：

    C/C++：典型编译型语言
    Python：按解释型语言理解

## 六、Python 程序运行的直观理解

一个 Python 源文件通常以 .py 结尾，例如：

    hello.py

运行时由 Python 解释器读取并执行：

    python hello.py

其中：

- python：Python 解释器
- hello.py：Python 源程序

## 七、本章最该记住

1. Python 是一种语法简洁、库丰富、跨平台的语言。
2. PyCharm/Jupyter 是开发或交互环境，不是 Python 语言本身。
3. 编译：先整体翻译，再运行。
4. 解释：边翻译边执行。
5. Python 程序通常保存为 .py 文件，由 Python 解释器运行。
