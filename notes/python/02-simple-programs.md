## 二、变量与标识符

Python 变量在使用前必须先赋值。

    a = 10
    name = "Tom"

查看对象类型：

    type(a)

标识符规则：

- 由字母、数字、下划线组成。
- 不能以数字开头。
- 区分大小写。
- 不能使用 Python 保留字。

## 三、赋值

普通赋值：

    x = 3

同时赋值：

    a, b = 3, 4

交换：

    a, b = b, a

链式赋值：

    a = b = c = 15

PPT 的解释是：先创建整数对象 15，再把三个变量都赋为该值。

## 四、常用运算

    100 / 3     # 普通除法
    100 // 3    # 向下整除
    100 % 3     # 取余
    2 ** 5      # 幂

关系运算：

    <  <=  >  >=  ==  !=

逻辑运算：

    and
    or
    not

## 五、注释与缩进

单行注释：

    # 这是注释

Python 使用缩进表示代码块，课程中按“一个缩进通常 4 个空格”理解。

## 六、输入与输出

输出：

    print("hello")

多个表达式：

    print(a, b, a + b)

输入：

    name = input("请输入名字：")

input() 得到的是字符串。

需要数字时可转换：

    age = int(input("请输入年龄："))

PPT 还介绍了：

    eval("1 + 2")

eval() 会把字符串按 Python 表达式解析并执行。

## 七、字符串

字符串可以用单引号或双引号表示：

    s = "Python"

索引从 0 开始：

    s[0]   # 'P'

字符串、列表等序列都可通过索引访问元素。

## 八、字符编码

### ASCII

主要用于英文字符。

### GBK

在 GB2312 基础上扩展，兼容 ASCII，可表示大量中文字符。

### Unicode

目标是为世界各种语言字符建立统一编码体系。

### UTF-8

Unicode 的一种常见实现方式，是可变长度编码。

记忆：

Unicode 更像“字符统一编号体系”；UTF-8 是常见的存储和传输编码方式。

## 九、math 库

导入整个库：

    import math
    math.sqrt(25)

导入指定函数：

    from math import sqrt
    sqrt(25)

PPT 中常见内容：

- math.pi
- math.e
- math.ceil(x)：向上取整
- math.floor(x)：向下取整
- math.factorial(x)：阶乘
- math.gcd(a, b)：最大公约数
- math.sqrt(x)：平方根
- math.pow(x, y)：幂
- math.log()、log2()、log10()
- sin()、cos()、tan()

## 十、本章易错点

- = 是赋值，== 是比较相等。
- / 与 // 不同。
- input() 默认返回字符串。
- 字符串索引从 0 开始。
- 导入整个 math 时调用函数需要写 math.xxx()。
