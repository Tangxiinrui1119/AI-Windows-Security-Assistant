## 二、字符串常用方法

### split()

按指定分隔符拆分字符串，返回列表。

    "a,b,c".split(",")
    # ["a", "b", "c"]

### join()

用指定分隔符连接序列中的字符串。

    ",".join(["a", "b", "c"])
    # "a,b,c"

### strip()

移除字符串首尾指定字符；未指定时默认处理空格、换行、制表等。

### count()

统计子字符串出现次数。

### startswith() / endswith()

判断字符串开头 / 结尾是否符合指定内容，返回 True / False。

### replace()

替换字符串内容。

## 三、字符串格式化

PPT 介绍三类：

### %

旧式格式化。

### str.format()

    "{} {}".format(a, b)

槽位可控制参数序号、填充、对齐、宽度、千位分隔、精度和类型。

### f-string

Python 3.6 之后加入：

    name = "Lily"
    age = 18
    f"{name} is {age} years old"

格式化：

    f"{x:.2f}"

表示保留 2 位小数。

## 五、正则表达式是什么

正则表达式用于描述“字符串应满足什么规则”，从而搜索或匹配字符串模式。

## 六、常用正则符号

    .        任意字符
    []       字符集合
    |        或
    *        前一规则 0 次或多次
    +        前一规则 1 次或多次
    ?        前一规则 0 次或 1 次
    {n}      正好 n 次
    {m,n}    m 到 n 次
    ^        字符串开头
    $        字符串结尾
    ()       分组

特殊序列：

    d   数字
    D   非数字
    w   字母、数字、下划线
    W   与 w 相反
    s   空白字符
    S   非空白字符

例如：

    d+

表示一个或多个连续数字。

## 七、re 模块

导入：

    import re

### search()

扫描整个字符串，找第一个匹配。

### findall()

找出所有匹配，返回列表。

### finditer()

作用类似 findall，但返回迭代器，适合较大数据。

### match()

只从字符串开头开始匹配。

### fullmatch()

要求从头到尾完整匹配。

### split()

按正则匹配规则拆分字符串。

### sub()

替换匹配到的内容，返回替换后的字符串。

### subn()

返回：

    (替换后的字符串, 替换次数)

### compile()

把模式字符串编译成正则表达式对象，便于重复使用。

## 八、匹配失败

匹配不上通常不是程序报错。

例如 match() 找不到时会返回：

    None

## 九、异常处理

PPT 后半部分介绍：

    try:
        可能发生异常的代码
    except 某异常类型:
        异常处理代码

可以有多个 except。

还可配合：

    else
    finally

其中 finally 中的代码无论是否发生异常都会执行。
