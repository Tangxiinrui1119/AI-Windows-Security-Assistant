## 一、整除和因子（第 2–5 页）

设 `a,b∈ℤ` 且 `b≠0`。若存在整数 `q` 使 `a=bq`，记作 `b∣a`，读作「b 整除 a」。此时 b 是 a 的因子，a 是 b 的倍数。

- 传递性。若 `c∣b` 且 `b∣a`，则 `c∣a`。
- 同乘。若 `b∣a`，则 `bc∣ac`（课件取 `b,c>0`）。
- 线性组合。若 `c∣a` 且 `c∣b`，则对整数 m、n 有 `c∣(ma+nb)`。

**例题。** `n³−n=(n−1)n(n+1)`，三个连续整数中恰有一个是 3 的倍数，所以 `3∣(n³−n)`。若 `n=3k=4l`，则 `4n−3n=12k−12l=12(k−l)`，所以 `12∣n`。

## 二、素数与判定（第 6–10 页）

大于 1、只有 1 和自身两个正因子的正整数称为**素数**。大于 1 的非素数称为**复合数**，简称合数。素数有无穷多个。课件还以素数计数、哥德巴赫猜想、陈景润的「1+2」和孪生素数猜想说明素数研究的背景。

- **梅森数**为 `Mₙ=2^n−1`。课件把指数 n 为素数且 Mₙ 也为素数的情形称为梅森素数。
- **费马素数**是形如 `Fₙ=2^(2^n)+1` 的素数。
- **试除判定。** 若 `N>1` 为合数，它必有一个不超过 `√N` 的素因子。逐个试除这些素数即可判定。
- **埃拉托色尼斯筛法。** 从 2 到 N 保留素数 p 本身，划去 p 的大于 p 的倍数。只需用 `p≤√N` 的素数筛。课件例取 `N=100`，用 2、3、5、7 筛除合数。

## 三、带余除法与最大公因数（第 11–18 页）⭐⭐⭐

**定理 1.1（带余除法）。** 对整数 a、b，若 `b>0`，则有唯一的整数 q、r 满足 `a=bq+r，0≤r<b`。课件称 q 为不完全商。r 是 `a−kb` 中最小的非负数。若有两个余数，它们的差是 b 的倍数且绝对值小于 b，只能等于零。即使 a 为负，仍按这个范围选余数，例如 `−17=5×(−4)+3`。

公因数是同时整除给定整数的正整数。最大公因数记为 `(a,b)` 或 `gcd(a,b)`。`(a,b)=1` 时称 a、b **互素**。

| 课件性质 | 计算中的用法 |
| --- | --- |
| `(a,b)=(b,a)=(abs(a),abs(b))` | 交换顺序或改变符号不影响最大公因数 |
| `b>0` 且 `b∣a` 时 `(a,b)=b`，另有 `(0,b)=abs(b)`（b 非零） | 处理整除和零余数 |
| `(ca₁,…,caₙ)=c(a₁,…,aₙ)`（c 为正整数） | 提取公因子。d 为正公因数时 `(a/d,b/d)=(a,b)/d` |
| `(a₁,…,aₙ)=((a₁,…,aₙ₋₁),aₙ)` | 从非零整数开始，依次求两个数的最大公因数 |
| `a∣bc` 且 `(a,b)=1`，则 `a∣c` | 用互素条件消去一个因子 |
| `(a,c)=(b,c)=1`，则 `(ab,c)=1` | 两个与 c 互素的数相乘后仍与 c 互素 |

## 四、辗转相除法与扩展 Euclid 算法（第 19–26 页）⭐⭐⭐

**定理 1.2。** 若 `a=bq+r`，则 `(a,b)=(b,r)`。公因数整除 a、b 时也整除 `r=a−bq`，整除 b、r 时也整除 `a=bq+r`。两组公因数完全相同。

**课件例题。** 连续计算 `172=3×46+34`、`46=34+12`、`34=2×12+10`、`12=10+2`、`10=5×2`。最后一个非零余数是 2，因此 `(172,46)=2`。

**定理 1.3（Bézout 等式）。** 对正整数 a、b，存在整数 s、t，使 `as+bt=(a,b)`。因此任意公因数都整除最大公因数。扩展 Euclid 算法在求余数的同时记录它是 a 和 b 的哪组线性组合。

```text
X ← (1, 0, a)
Y ← (0, 1, b)
当 Y 的第三项非零时
    q ← X 的第三项除以 Y 的第三项所得的整数商
    (X, Y) ← (Y, X − qY)
返回 X = (s, t, gcd(a,b))
```

**课件例题。** `1859=1573+286`，`1573=5×286+143`，`286=2×143`。回代得到 `143=1573−5(1859−1573)=−5×1859+6×1573`。互素时等式右边为 1，模 b 即得 a 的逆元，见第 2 章。

## 五、算术基本定理（第 27–30 页）

**定理 1.4。** 若 p 为素数且 `p∣ab`，则 `p∣a` 或 `p∣b`。证明中若 `p∤a`，就有 `au+pv=1`。两边乘 b 后，右边 b 是 `abu+pbv`，每项均被 p 整除。

**定理 1.5（算术基本定理）。** 任一整数 `n>1` 唯一写成标准分解式 `n=p₁^α₁⋯pₖ^αₖ`，其中 `p₁<⋯<pₖ` 为素数，指数均为正整数。存在性来自反复取最小的大于 1 的因子。唯一性来自定理 1.4，可逐个消去两边相同的素因子。

## 六、最小公倍数（第 31–36 页）

`[a₁,…,aₙ]` 是这些非零整数的正公倍数，并整除它们的每一个正公倍数。

- **定理 1.6。** 依次合并两个整数求最小公倍数，例如 `[a,b,c]=[[a,b],c]`。
- **定理 1.7。** 正整数 a、b 满足 `[a,b]=ab/(a,b)`。用标准分解式计算时，最大公因数取每个素因子的最小指数，最小公倍数取最大指数。缺少的素因子按指数 0 计。
- **课件例题。** `45=3²×5`、`100=2²×5²`，所以 `(45,100)=5`、`[45,100]=900`。对 `120,150,210,35`，共同素因子只剩一个 5，故最大公因数为 5，最小公倍数为 `2³×3×5²×7=4200`。

## 易混淆点

- 互素描述两个整数之间的关系。例如 8 与 15 互素，两者都是合数。
- 欧几里得算法停在余数为 0 时，答案取前一步的非零余数。要继续求 s、t，就保留各步商或同步更新系数。
- 对多组整数做分解时，求最大公因数要把缺失的素因子也计入指数比较。
