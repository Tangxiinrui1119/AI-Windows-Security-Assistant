## 知识地图

```text
一次同余方程
├── 同余方程的解 → 按模数计剩余类
├── ax ≡ b (mod m)
│   ├── gcd(a,m) ∤ b → 无解
│   └── gcd(a,m) ∣ b → 约化 → 求逆 → 还原全部解
└── 一次同余方程组
    ├── 模数两两互素 → 中国剩余定理
    ├── 合数模拆分 → 逐个模数求解 → 合并

```

## 3.1 一次同余方程（第 2–24 页）

### 解与解数

设整系数多项式 `f(x)=aₙx^n+⋯+a₁x+a₀`，模数 m 为正，且最高次系数满足 `m∤aₙ`。若 `f(u)≡0 (mod m)`，所有满足 `x≡u (mod m)` 的整数 x 都是解。**解数**按模 m 两两不同的剩余类计。m 小时可遍历任一完全剩余系。

| 课件例题 | 结果 |
| --- | --- |
| 例 3.1.1，`5x≡3 (mod 7)` | `x≡2 (mod 7)` |
| 例 3.1.2，`4x≡2 (mod 6)` | `x≡2,5 (mod 6)` |
| 例 3.1.3，`3x≡2 (mod 6)` | 无解 |
| 例 3.1.4，`4x²+27x−12≡0 (mod 15)` | 遍历 −7 到 7，得 `x≡−6,3 (mod 15)` |

### 有解条件、模逆与通解 ⭐⭐⭐

**定理 3.1.1–3.1.2。** 当 `(a,m)=1` 时，`ax≡1 (mod m)` 有唯一解 `x≡a⁻¹ (mod m)`。再乘 b 得到 `ax≡b (mod m)` 的唯一解 `x≡a⁻¹b (mod m)`。唯一性也可由同乘 a 后仍是完全剩余系得出。

**定理 3.1.3。** 令 `d=(a,m)`。`ax≡b (mod m)` 有解当且仅当 `d∣b`。有解时，恰有 d 个模 m 不同的解。

1. 检查 `d∣b`。因为 `ax−my=b`，左边一定被 d 整除。
2. 若可整除，令 `a'=a/d，b'=b/d，m'=m/d`。原式等价于 `a'x≡b' (mod m')`。
3. `(a',m')=1`，用扩展欧几里得算法求出逆元，取一个特解 `x₀≡(a')⁻¹b' (mod m')`。若 `m'=1`，约化式对所有整数成立，可取 `x₀=0`。
4. 还原为 `x≡x₀+t·m' (mod m)，t=0,1,…,d−1`。任何两个原方程的解之差都被 m' 整除，而这 d 个偏移模 m 两两不同。

**例 3.1.5–3.1.7。** `1=7×28−13×15`，所以 `15⁻¹≡−13≡15 (mod 28)`。于是 `15x≡3 (mod 28)` 的解为 `x≡3×15≡17 (mod 28)`。对于 `45x≡9 (mod 84)`，除以公因数 3 后正好得到这个约化式。原模 84 下的三个解为 `17,45,73`。

**例 3.1.8。** `69x≡12 (mod 111)` 约化为 `23x≡4 (mod 37)`。由 `1=5×37−8×23`，得到 `x≡4×(−8)≡5 (mod 37)`。按模 111 展开为 `x≡5,42,79 (mod 111)`，与课件写法 `79+37t，t=0,1,2` 等价。

## 3.2 一次同余方程组（第 25–45 页）

### 中国剩余定理（CRT，孙子定理）⭐⭐⭐

**定理 3.2.1。** 设正整数 `m₁,…,mₖ` 两两互素。方程组 `x≡bᵢ (mod mᵢ)` 在模 `M=m₁⋯mₖ` 下有唯一解。取 `Mᵢ=M/mᵢ`，求逆元 `uᵢ≡Mᵢ⁻¹ (mod mᵢ)`，则

```text
x ≡ Σᵢ bᵢMᵢuᵢ (mod M)。
```

在模 mᵢ 下，`Mᵢuᵢ≡1`，而任意 `j≠i` 的 `Mⱼuⱼ≡0`。因此求和在每个模数下都保留对应的余数。任意两个解的差同时被各 mᵢ 整除，因两两互素也就被 M 整除，这给出唯一性。

**例 3.2.1，《孙子算经》「物不知数」。** 按模 3、5、7 的余数分别为 2、3、2。`M=105`，三个 `Mᵢ` 为 35、21、15，其逆元分别为 2、1、1。代入得 `35×2×2+21×1×3+15×1×2=233≡23 (mod 105)`。正整数解为 `23+105k，k=0,1,2,…`。课件把这个问题与秦九韶《数书九章》的通法联系起来。

**例 3.2.3，计算 `3^1000 mod 391`。** `391=17×23`。用费马小定理分别降指数，得 `3^1000≡3⁸≡16 (mod 17)` 与 `3^1000≡3^10≡8 (mod 23)`。`23⁻¹≡3 (mod 17)`，`17⁻¹≡−4 (mod 23)`，所以可用 `23×3×(−1)+17×(−4)×8≡169 (mod 391)` 合并。

### 多项式同余的解数

**定理 3.2.2。** 当 `M=m₁⋯mₖ` 且各因子两两互素时，`f(x)≡0 (mod M)` 等价于每个 `f(x)≡0 (mod mᵢ)` 同时成立。每个局部方程各选一个根，再用 CRT 拼成唯一的全局根。同一组局部根只对应一个全局剩余类，因此

```text
T(M;f) = T(m₁;f) × ⋯ × T(mₖ;f)。
```

其中 `T(m;f)` 是 f 模 m 的解数。任意一项为零，原方程就无解。第 4 章用它处理合数模下的二次同余。

### 课件的扩展题型

| 题型 | 课件例题的解法 |
| --- | --- |
| 模数小，直接找共同解（第 35 页） | `x≡1 (mod 3)`、`x≡5 (mod 8)` 的共同解为 `x≡13 (mod 24)` |
| 系数为大幂（第 41 页） | `2^2011x≡10 (mod 77)`。因 `φ(77)=60`，先算 `2^2011≡2^31≡2 (mod 77)`，再解得 `x≡5 (mod 77)` |
| 模数并非两两互素（例 3.2.5） | `x≡3 (mod 8)`、`x≡11 (mod 20)`、`x≡1 (mod 15)`。把 20 拆为 4、5，15 拆为 3、5，去掉重复或已蕴含的条件，保留模 8 余 3、模 5 和模 3 余 1。得 `x≡91≡−29 (mod 120)` |
| 系数不为 1、需要分支（例 3.2.6） | `x≡3 (mod 7)` 与 `6x≡10 (mod 8)`。第二式有 `x≡3,7 (mod 8)` 两个分支，分别合并得到 `x≡3,31 (mod 56)` |
| 两个未知数（例 3.2.7） | `3x+y≡7 (mod 23)`、`x+2y≡6 (mod 23)`。第一式乘 2 再减第二式，得 `5x≡8 (mod 23)`。乘逆元 14 得 `x≡20 (mod 23)`，回代得 `y≡16 (mod 23)` |

## 易混淆点

- 单方程中先检查 d 是否整除 b，再去求逆。约化式模 `m/d` 的一个解会对应原模 m 下的 d 个类。
- CRT 的唯一性是模 M 的唯一性。拆分不互素模数时，要核对重复条件是否一致，不能把原模数直接相乘套公式。
